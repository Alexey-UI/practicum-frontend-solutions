# Mesto: валидация форм и сборка

Учебный проект на основе официальной заготовки Yandex-Practicum/mesto-ad.

Node.js 22.18+. Установка: `npm ci`. Разработка: `npm run dev`, сборка: `npm run build`, просмотр сборки: `npm run preview`.

Три формы проверяются через HTML5 validity и переиспользуемый модуль validation.js. Ошибки очищаются при открытии; кнопка активируется после изменения валидных данных. Сохранены просмотр изображений, лайки, удаление карточек и редактирование профиля. Эта часть проекта проверяется самостоятельно по чек-листу курса.
