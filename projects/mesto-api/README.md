# Mesto: работа с сервером

Продолжение проекта Mesto: учебный API, валидация трёх форм, серверные лайки, удаление собственных карточек и статистика карточки (вариант 1).

Node.js 22.18+. `npm ci` — установка, `npm run dev` — разработка, `npm run build` — сборка, `npm run deploy` — публикация dist на GitHub Pages. Сайт: https://alexey-ui.github.io/mesto-ad/

Личный токен и идентификатор группы вводятся в диалоге подключения. Они хранятся только в sessionStorage текущей вкладки и не входят в код или сборку. Автоматического запроса токена через внешние формы нет.

Серверная часть проверяется локально с имитацией API; подключение к настоящему учебному серверу и сдача ревьюеру пока не подтверждены.
