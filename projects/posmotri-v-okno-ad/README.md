# Посмотри в окно

Оформление приложения поиска видео городов: фиксированный макет, карточки с
прокруткой, состояния элементов формы и навигация с клавиатуры.
Исходная разметка, шаблоны и логика JavaScript сохранены.

Откройте `index.html` через локальный HTTP-сервер. Для получения видео требуется
доступ к API Практикума.

Репозиторий: https://github.com/Alexey-UI/posmotri-v-okno-ad
