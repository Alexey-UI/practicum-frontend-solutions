# Оно тебе надо

Страница аукциона вещей, в которые никто не верил. Первая проектная работа
курса «Ассоциированные программы: Фронтенд-разработка» Яндекс Практикума.

Репозиторий: https://github.com/Alexey-UI/ono-tebe-nado-ad

HTML5, CSS Grid и Flexbox, локальные шрифты Raleway, семантическая разметка.
Макет рассчитан на ширину 1100 px. Для просмотра откройте `index.html` в браузере;
сборка и установка зависимостей не требуются.

Изображения, шрифты и начальная структура взяты из заготовки курса.
Официальная автоматическая проверка запускается GitHub Actions при push.
