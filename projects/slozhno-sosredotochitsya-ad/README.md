# Сложно сосредоточиться

Адаптивная страница по макету Яндекс Практикума: светлая, тёмная и системная темы; сетка галереи и управление с клавиатуры.

Репозиторий: https://github.com/Alexey-UI/slozhno-sosredotochitsya-ad

Откройте `index.html` в браузере. Исходный скрипт переключения темы и официальный workflow проверки сохранены.
